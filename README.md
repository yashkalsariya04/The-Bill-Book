# The Bill Book

An offline-first React Native bill book for brick purchases.

## Features

- Create brick purchase bills with purchaser, seller, quantity, price, vehicle number, date, and signature name.
- Calculates total amount automatically.
- Stores bills locally with SQLite for offline use.
- View previous bills and filter by purchaser or seller.
- Capture the bill preview as an image and share it through WhatsApp or any app supported by the phone.

## Run

```bash
npm install
npm run start
```

Then open the app with Expo Go or an Android/iOS simulator.
